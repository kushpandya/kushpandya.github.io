## About

This is a static site hosted for free on **GitHub Pages**.

## Enable GitHub Pages (required once)

1. Go to the repository: https://github.com/kushpandya/kushpandya.github.io
2. Click **Settings** → **Pages** (left sidebar under "Code and automation")
3. Under **Build and deployment** → **Source**, select **Deploy from a branch**
4. Branch: **main**  /  Folder: **/ (root)**
5. Click **Save**

After a minute or two the site will be live at https://kushpandya.github.io
